# Skill sounds

One mp3 per skill, named after the skill's slug (its name in lowercase with dashes). Drop a file in this folder and that skill plays it
whenever it is cast, in the arena and on the floors. A skill with no file keeps its old behaviour (the arena's short synthesized
blips; the floors stay quiet). Short clips work best: under about 1.5 seconds, with the swing and the impact together in the same file.

The first two are wired and waiting for their recordings:

- `basic-strike.mp3`
- `first-aid.mp3`
